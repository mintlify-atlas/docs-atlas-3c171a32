These conventions apply throughout the UFO specification. Understanding them is essential for correctly reading, writing, and interoperating with UFO data across authoring tools and platforms.

## Allowed Content Types

UFOs may contain only plain files or directories. Symlinks are **not** allowed anywhere in a UFO package. They increase the number of edge cases implementations must handle without providing clear benefit, and they complicate data exchange across different platforms.

## XML Property Lists

XML property lists are used throughout the UFO specification. [A DTD is available from Apple.](http://www.apple.com/DTDs/PropertyList-1.0.dtd)

<Tip>
It is recommended, but not required, that dictionaries in property lists be written in ascending order based on their keys. This makes UFO usage more predictable in revision control systems and simplifies automated diffing.
</Tip>

## Coordinate System

Coordinates and transformations in the UFO are relative to the origin (`x=0`, `y=0`). The positive x-axis points right and the positive y-axis points **up**, unless otherwise noted in a specific part of the specification.

## Data Types

The following types are used throughout the UFO specification. While efforts have been made to define how UFO values relate to binary formats such as OpenType, it is the responsibility of authoring tools to ensure UFO values convert to the corresponding binary values appropriately. For example, many OpenType fields require unsigned short integers, but a UFO may legally contain values for those fields that are greater than 65,535.

### string

A string is specified with one or more characters encoded with the encoding scheme defined for the XML file that the string belongs to. The range of characters allowed in a given string field may be further restricted — in those cases the specification defines the available subset.

### integer

An integer is specified with an optional sign character (`+` or `-`) followed by one or more digits `0` to `9`. There is no limit to the number of integer digits. If a sign character is not present, the number is non-negative.

### non-negative integer

An integer that is greater than or equal to zero. Uses the same notation as integer above.

### float

A float is specified with an optional sign character (`+` or `-`) followed by zero or more digits `0` to `9`, followed by a period `.`, followed by one or more digits `0` to `9`. There is no limit to the number of digits before or after the decimal point. If a sign character is not present, the number is non-negative.

<Warning>
Only **normal** and **zero** float types are allowed. `NaN`, infinite, and subnormal floats are explicitly disallowed. Authoring tools should not write floats that can be represented losslessly as integers unless the specification requires a float for that field.
</Warning>

### non-negative float

A float that is greater than or equal to zero. Uses the same notation as float above.

### list

An ordered collection of items. The order of items is insignificant unless otherwise stated for a particular list in the specification.

### dictionary

An unordered associative array mapping keys to values. In the XML property lists used throughout the UFO, keys must be strings. Values may be any type, with the specific options defined throughout the specification.

### color definition

A color definition is a string containing a comma-separated sequence of four integers or floats, each between `0` and `1` inclusive. White space characters are allowed around the numerical values. The four values define the **red**, **green**, **blue**, and **alpha** components of the color, in that order. The color is always specified in the [sRGB](http://en.wikipedia.org/wiki/SRGB) color space.

| String | Red | Green | Blue | Alpha |
|--------|-----|-------|------|-------|
| `1,0,0,1` | 1.0 | 0 | 0 | 1.0 |
| `0,.5,0,.5` | 0 | 0.5 | 0 | 0.5 |

### control characters

Any character with a Unicode value in the following ranges is considered a control character:

- `U+0000`–`U+001F` — C0 controls
- `U+007F` — delete
- `U+0080`–`U+009F` — C1 controls

## Identifiers

Identifiers are optional attributes of several objects in the UFO. They are required to be unique within specific contexts as defined on a per-object basis throughout the specification.

<Info>
An identifier is a string between **1 and 100 characters** long. All characters must be in the **printable ASCII range**, `0x20` to `0x7E`.
</Info>

There is no standard identifier generation algorithm. Random strings, simple numbers, UUIDs, timestamps, and more may all be used. An example algorithm for generating random string identifiers is provided below.

### Example Algorithm

This algorithm generates a unique identifier that is a random string of 10 characters drawn from `0–9`, `A–Z`, and `a–z`. This allows a single glyph to contain up to 10⁶² identifiable points when following this scheme.

<Steps>
  <Step title="Define possible characters">
    The set of possible characters includes `0–9`, `A–Z`, and `a–z`.
  </Step>
  <Step title="Collect existing identifiers">
    Gather a list of all existing identifiers in the current scope (e.g. the current glyph).
  </Step>
  <Step title="Generate a candidate">
    Produce a 10-character string by randomly selecting characters from the possible characters set.
  </Step>
  <Step title="Check uniqueness">
    If the candidate is not already in the existing identifiers list, stop — it is the new identifier. Otherwise, repeat from step 3.
  </Step>
</Steps>

### Example Implementation

```python
import random

characters = list("0123456789")
characters += list("ABCDEFGHIJKLMNOPQRSTUVWXYZ")
characters += list("abcdefghijklmnopqrstuvwxyz")
identifierLength = 10
identifierRange = range(identifierLength)

def makeRandomIdentifier(existing, recursionDepth=0):
    if recursionDepth >= 50:
        raise NotImplementedError, \
            "Failed 50 times in a row to create a unique id. Sorry."
    identifier = []
    for i in identifierRange:
        c = random.choice(characters)
        identifier.append(c)
    identifier = "".join(identifier)
    if identifier in existing:
        return makeRandomIdentifier(existing, recursionDepth+1)
    else:
        return identifier
```

## Reverse Domain Naming Schemes

In several places in the UFO the [reverse domain naming system](http://en.wikipedia.org/wiki/Reverse-DNS) is recommended for creating unique keys and identifiers. To form a reverse domain name, reverse the relevant Internet domain. For example, the Internet domain `unifiedfontobject.org` becomes `org.unifiedfontobject`. Further extensions may be appended to make the string unique, for example `org.unifiedfontobject.MySpecialTool`.

<Note>
The name `public.*` — where `*` is an arbitrary string of one or more characters — is **reserved** for use by data structures that are part of the UFO specification itself. Third-party tools must not use this prefix.
</Note>

## Common User Name to File Name Algorithm

There is no universally mandated user name to file name conversion, but the algorithm below is a widely used example. It is designed to avoid name clashes and work correctly with common file systems by applying the following rules:

1. Filenames must be unique.
2. Filenames must be case-insensitive.
3. Filenames may use any character representable in UTF-8, except those reserved across popular file systems.
4. Filenames must be no longer than 255 characters.
5. Filenames (regardless of extension and case) must not match any of the [Windows reserved file names](https://docs.microsoft.com/en-gb/windows/win32/fileio/naming-a-file#naming-conventions).
6. Filenames must be valid Unicode strings.

### Algorithm Steps

<Steps>
  <Step title="Set up variables">
    - *name* is the user name without any required prefix or suffix.
    - *maximum length* is 255 minus the combined length of any prefix and suffix that will be added to the name.
  </Step>
  <Step title="Translate illegal characters">
    Replace any illegal characters in *name* with underscores (`_`). Illegal characters are:

    `"` `(` `)` `*` `+` `/` `:` `<` `>` `?` `[` `\` `]` `|`

    and anything in the ASCII control character range (U+0000–U+001F inclusive and U+007F).
  </Step>
  <Step title="Mark uppercase characters">
    Insert an underscore (`_`) immediately after every uppercase character.
  </Step>
  <Step title="Handle leading period">
    If the name begins with a period and no prefix will be added, replace the leading period with an underscore.
  </Step>
  <Step title="Clip to maximum length">
    If the revised name is longer than *maximum length*, remove characters from the end until it fits.
  </Step>
  <Step title="Handle Windows reserved names">
    Split the name on periods (`.`). For each part, if a case-insensitive comparison matches any Windows reserved file name (`CON`, `CLOCK$`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, `LPT1`–`LPT9`), insert an underscore at the beginning of that part. Rejoin all parts with periods.
  </Step>
  <Step title="Ensure uniqueness">
    If the full name (with prefix and suffix) is case-insensitively unique in the existing file list, stop. Otherwise:

    - Trim the name to (*maximum length* − 15) characters.
    - Append a 15-character zero-padded counter starting at `000000000000001`.
    - Increment the counter until a unique name is found or `999999999999999` is reached.

    If still not unique, use a plain incrementing number as the entire name until a unique value is found or all possible numbers up to the maximum length are exhausted. If no unique name can be found, raise an error.
  </Step>
</Steps>

### Naming Examples

| Glyph Name | File Name |
|------------|-----------|
| `a` | `a` |
| `A` | `A_` |
| `AE` | `A_E_` |
| `Ae` | `A_e` |
| `ae` | `ae` |
| `aE` | `aE_` |
| `a.alt` | `a.alt` |
| `A.alt` | `A_.alt` |
| `A.Alt` | `A_.A_lt` |
| `A.aLt` | `A_.aL_t` |
| `A.alT` | `A_.alT_` |
| `T_H` | `T__H_` |
| `T_h` | `T__h` |
| `t_h` | `t_h` |
| `F_F_I` | `F__F__I_` |
| `f_f_i` | `f_f_i` |
| `Aacute_V.swash` | `A_acute_V_.swash` |
| `.notdef` | `_notdef` |
| `con` | `_con` |
| `CON` | `C_O_N_` |
| `con.alt` | `_con.alt` |
| `alt.con` | `alt._con` |

### Example Implementation

```python
illegalCharacters = "\" * + / : < > ? [ \\ ] | \0".split(" ")
illegalCharacters += [chr(i) for i in range(1, 32)]
illegalCharacters += [chr(0x7F)]
reservedFileNames = "CON PRN AUX CLOCK$ NUL A:-Z: COM1".lower().split(" ")
reservedFileNames += "LPT1 LPT2 LPT3 COM2 COM3 COM4".lower().split(" ")
maxFileNameLength = 255

def userNameToFileName(userName, existing=[], prefix="", suffix=""):
    """
    existing should be a case-insensitive list
    of all existing file names.

    >>> userNameToFileName(u"a")
    u'a'
    >>> userNameToFileName(u"A")
    u'A_'
    >>> userNameToFileName(u"AE")
    u'A_E_'
    >>> userNameToFileName(u"Ae")
    u'A_e'
    >>> userNameToFileName(u"ae")
    u'ae'
    >>> userNameToFileName(u"aE")
    u'aE_'
    >>> userNameToFileName(u"a.alt")
    u'a.alt'
    >>> userNameToFileName(u"A.alt")
    u'A_.alt'
    >>> userNameToFileName(u"A.Alt")
    u'A_.A_lt'
    >>> userNameToFileName(u"A.aLt")
    u'A_.aL_t'
    >>> userNameToFileName(u"A.alT")
    u'A_.alT_'
    >>> userNameToFileName(u"T_H")
    u'T__H_'
    >>> userNameToFileName(u"T_h")
    u'T__h'
    >>> userNameToFileName(u"t_h")
    u't_h'
    >>> userNameToFileName(u"F_F_I")
    u'F__F__I_'
    >>> userNameToFileName(u"f_f_i")
    u'f_f_i'
    >>> userNameToFileName(u"Aacute_V.swash")
    u'A_acute_V_.swash'
    >>> userNameToFileName(u".notdef")
    u'_notdef'
    >>> userNameToFileName(u"con")
    u'_con'
    >>> userNameToFileName(u"CON")
    u'C_O_N_'
    >>> userNameToFileName(u"con.alt")
    u'_con.alt'
    >>> userNameToFileName(u"alt.con")
    u'alt._con'
    """
    # the incoming name must be a unicode string
    assert isinstance(userName, unicode), \
        "The value for userName must be a unicode string."
    # establish the prefix and suffix lengths
    prefixLength = len(prefix)
    suffixLength = len(suffix)
    # replace an initial period with an _
    # if no prefix is to be added
    if not prefix and userName[0] == ".":
        userName = "_" + userName[1:]
    # filter the user name
    filteredUserName = []
    for character in userName:
        # replace illegal characters with _
        if character in illegalCharacters:
            character = "_"
        # add _ to all non-lower characters
        elif character != character.lower():
            character += "_"
        filteredUserName.append(character)
    userName = "".join(filteredUserName)
    # clip to 255
    sliceLength = maxFileNameLength - prefixLength - suffixLength
    userName = userName[:sliceLength]
    # test for illegal file names
    parts = []
    for part in userName.split("."):
        if part.lower() in reservedFileNames:
            part = "_" + part
        parts.append(part)
    userName = ".".join(parts)
    # test for clash
    fullName = prefix + userName + suffix
    if fullName.lower() in existing:
        fullName = handleClash1(userName, existing, prefix, suffix)
    # finished
    return fullName

def handleClash1(userName, existing=[], prefix="", suffix=""):
    """
    existing should be a case-insensitive list
    of all existing file names.

    >>> prefix = ("0" * 5) + "."
    >>> suffix = "." + ("0" * 10)
    >>> existing = ["a" * 5]

    >>> e = list(existing)
    >>> handleClash1(userName="A" * 5, existing=e,
    ...     prefix=prefix, suffix=suffix)
    '00000.AAAAA000000000000001.0000000000'

    >>> e = list(existing)
    >>> e.append(prefix + "aaaaa" + "1".zfill(15) + suffix)
    >>> handleClash1(userName="A" * 5, existing=e,
    ...     prefix=prefix, suffix=suffix)
    '00000.AAAAA000000000000002.0000000000'

    >>> e = list(existing)
    >>> e.append(prefix + "AAAAA" + "2".zfill(15) + suffix)
    >>> handleClash1(userName="A" * 5, existing=e,
    ...     prefix=prefix, suffix=suffix)
    '00000.AAAAA000000000000001.0000000000'
    """
    prefixLength = len(prefix)
    suffixLength = len(suffix)
    if prefixLength + len(userName) + suffixLength + 15 > maxFileNameLength:
        l = (prefixLength + len(userName) + suffixLength + 15)
        sliceLength = maxFileNameLength - l
        userName = userName[:sliceLength]
    finalName = None
    counter = 1
    while finalName is None:
        name = userName + str(counter).zfill(15)
        fullName = prefix + name + suffix
        if fullName.lower() not in existing:
            finalName = fullName
            break
        else:
            counter += 1
        if counter >= 999999999999999:
            break
    if finalName is None:
        finalName = handleClash2(existing, prefix, suffix)
    return finalName

def handleClash2(existing=[], prefix="", suffix=""):
    """
    existing should be a case-insensitive list
    of all existing file names.

    >>> prefix = ("0" * 5) + "."
    >>> suffix = "." + ("0" * 10)
    >>> existing = [prefix + str(i) + suffix for i in range(100)]

    >>> e = list(existing)
    >>> handleClash2(existing=e, prefix=prefix, suffix=suffix)
    '00000.100.0000000000'

    >>> e = list(existing)
    >>> e.remove(prefix + "1" + suffix)
    >>> handleClash2(existing=e, prefix=prefix, suffix=suffix)
    '00000.1.0000000000'

    >>> e = list(existing)
    >>> e.remove(prefix + "2" + suffix)
    >>> handleClash2(existing=e, prefix=prefix, suffix=suffix)
    '00000.2.0000000000'
    """
    maxLength = maxFileNameLength - len(prefix) - len(suffix)
    maxValue = int("9" * maxLength)
    finalName = None
    counter = 1
    while finalName is None:
        fullName = prefix + str(counter) + suffix
        if fullName.lower() not in existing:
            finalName = fullName
            break
        else:
            counter += 1
        if counter >= maxValue:
            break
    if finalName is None:
        raise NameTranslationError("No unique name could be found.")
    return finalName
```
