The `fontinfo.plist` file is an XML property list that stores metadata about a font: its name, dimensions, legal information, OpenType table values, PostScript-specific settings, and Macintosh FOND resource data. This file is **optional** — not all keys are required, and the file may be omitted entirely if no font-level metadata needs to be recorded. All values are stored in a flat top-level dictionary.

<Note>
  The `fontinfo.plist` structure was completely redesigned for UFO 2. Keys are now tagged by format or OpenType table (e.g., `openTypeHheaAscender`). Data shared across multiple formats uses generic unprefixed keys (e.g., `familyName`). See the [conversion table](#converting-fontinfoplist-from-ufo-1-to-ufo-2) at the bottom of this page for a mapping from UFO 1 keys to UFO 2 keys.
</Note>

**File format:** XML Property List

These keys hold identification data that is not specific to any single output format or OpenType table.

## OpenType head Table Fields

These keys correspond to fields in the OpenType `head` table.

<ParamField body="openTypeHeadCreated" type="string">
  Creation date. Expressed as a string of the format `"YYYY/MM/DD HH:MM:SS"`. Month must be in the range 1–12; day in the range 1–end of month; hour in the range 0–23; minute and second each in the range 0–59.
</ParamField>

<ParamField body="openTypeHeadLowestRecPPEM" type="integer or float">
  Smallest readable size in pixels. Corresponds to the OpenType `head` table `lowestRecPPEM` field.
</ParamField>

<ParamField body="openTypeHeadFlags" type="number list">
  A list of bit numbers indicating the flags. Bit numbers are defined in the OpenType `head` specification. Corresponds to the `head` table `flags` field.
</ParamField>

<Info>
  The following `head` fields are derived or set by the compiler and do not have direct `fontinfo.plist` keys: `fontRevision` (from `versionMajor`/`versionMinor`), `checkSumAdjustment`, `magicNumber`, `unitsPerEm` (from generic key), `created` (from `openTypeHeadCreated`), `modified`, `xMin`/`yMin`/`xMax`/`yMax`, `macStyle` (from `styleMapStyleName`), `indexToLocFormat`, and `glyphDataFormat`.
</Info>

## OpenType OS/2 Table Fields

These keys correspond to fields in the OpenType `OS/2` table.

<ParamField body="openTypeOS2WidthClass" type="integer">
  Width class value. Must be in the range 1–9. Corresponds to `usWidthClass`.
</ParamField>

<ParamField body="openTypeOS2WeightClass" type="integer">
  Weight class value. Must be a positive integer. Corresponds to `usWeightClass`.
</ParamField>

<ParamField body="openTypeOS2Selection" type="number list">
  A list of bit numbers for `fsSelection` bits to set. **Note:** Bits 0 (italic), 5 (bold), and 6 (regular) should not be set here — they are derived from `styleMapStyleName`.
</ParamField>

<ParamField body="openTypeOS2VendorID" type="string">
  Four-character identifier for the creator of the font. Corresponds to `achVendID`.
</ParamField>

<ParamField body="openTypeOS2Panose" type="number list">
  A list of 10 integers representing the Panose classification. Corresponds to the `OS/2` table `Panose` field.
</ParamField>

<ParamField body="openTypeOS2FamilyClass" type="number list">
  Two integers representing the IBM font class ID (range 0–14) and font subclass (range 0–15). Corresponds to `sFamilyClass`.
</ParamField>

<ParamField body="openTypeOS2UnicodeRanges" type="number list">
  A list of bit numbers for supported Unicode ranges. Corresponds to `ulUnicodeRange1`–`ulUnicodeRange4`.
</ParamField>

<ParamField body="openTypeOS2CodePageRanges" type="number list">
  A list of bit numbers for supported code page ranges. Corresponds to `ulCodePageRange1` and `ulCodePageRange2`.
</ParamField>

<ParamField body="openTypeOS2TypoAscender" type="integer or float">
  Ascender value. Corresponds to `sTypoAscender`.
</ParamField>

<ParamField body="openTypeOS2TypoDescender" type="integer or float">
  Descender value. Corresponds to `sTypoDescender`.
</ParamField>

<ParamField body="openTypeOS2TypoLineGap" type="integer or float">
  Line gap value. Corresponds to `sTypoLineGap`.
</ParamField>

<ParamField body="openTypeOS2WinAscent" type="integer or float">
  Ascender value. Corresponds to `usWinAscent`.
</ParamField>

<ParamField body="openTypeOS2WinDescent" type="integer or float">
  Descender value. Corresponds to `usWinDescent`.
</ParamField>

<ParamField body="openTypeOS2Type" type="number list">
  A list of bit numbers indicating the embedding type. Corresponds to `fsType`.
</ParamField>

<ParamField body="openTypeOS2SubscriptXSize" type="integer or float">
  Subscript horizontal font size. Corresponds to `ySubscriptXSize`.
</ParamField>

<ParamField body="openTypeOS2SubscriptYSize" type="integer or float">
  Subscript vertical font size. Corresponds to `ySubscriptYSize`.
</ParamField>

<ParamField body="openTypeOS2SubscriptXOffset" type="integer or float">
  Subscript x offset. Corresponds to `ySubscriptXOffset`.
</ParamField>

<ParamField body="openTypeOS2SubscriptYOffset" type="integer or float">
  Subscript y offset. Corresponds to `ySubscriptYOffset`.
</ParamField>

<ParamField body="openTypeOS2SuperscriptXSize" type="integer or float">
  Superscript horizontal font size. Corresponds to `ySuperscriptXSize`.
</ParamField>

<ParamField body="openTypeOS2SuperscriptYSize" type="integer or float">
  Superscript vertical font size. Corresponds to `ySuperscriptYSize`.
</ParamField>

<ParamField body="openTypeOS2SuperscriptXOffset" type="integer or float">
  Superscript x offset. Corresponds to `ySuperscriptXOffset`.
</ParamField>

<ParamField body="openTypeOS2SuperscriptYOffset" type="integer or float">
  Superscript y offset. Corresponds to `ySuperscriptYOffset`.
</ParamField>

<ParamField body="openTypeOS2StrikeoutSize" type="integer or float">
  Strikeout size. Corresponds to `yStrikeoutSize`.
</ParamField>

<ParamField body="openTypeOS2StrikeoutPosition" type="integer or float">
  Strikeout position. Corresponds to `yStrikeoutPosition`.
</ParamField>

<Info>
  The following `OS/2` fields are calculated or set by the compiler: `xAvgCharWidth`, `fsSelection` (from `styleMapStyleName`), `usFirstCharIndex`, `usLastCharIndex`, `sxHeight` (from `xHeight`), `sCapHeight` (from `capHeight`), `usDefaultChar`, `usBreakChar`, and `usMaxContext`. Note: `sFamilyClass` is not supported for direct compiler output despite the `openTypeOS2FamilyClass` key being present in the spec.
</Info>

## PostScript Specific Data

These keys supply data for Type 1, CFF, and the OpenType `post` table.

<ParamField body="postscriptFontName" type="string">
  Name to be used for the `FontName` field in Type 1/CFF table.
</ParamField>

<ParamField body="postscriptFullName" type="string">
  Name to be used for the `FullName` field in Type 1/CFF table. If not given, can be created by combining `familyName` and `styleName`.
</ParamField>

<ParamField body="postscriptSlantAngle" type="float">
  Artificial slant angle.
</ParamField>

<ParamField body="postscriptUniqueID" type="integer">
  A unique ID number as defined in the Type 1/CFF specification.
</ParamField>

<ParamField body="postscriptUnderlineThickness" type="integer or float">
  Underline thickness value. Corresponds to the Type 1/CFF/`post` table `UnderlineThickness` field.
</ParamField>

<ParamField body="postscriptUnderlinePosition" type="integer or float">
  Underline position value. Corresponds to the Type 1/CFF/`post` table `UnderlinePosition` field.
</ParamField>

<ParamField body="postscriptIsFixedPitch" type="boolean">
  Indicates if the font is monospaced. A compiler could calculate this automatically, but the designer may override it. Corresponds to the Type 1/CFF `isFixedPitched` field.
</ParamField>

<ParamField body="postscriptBlueValues" type="number list">
  Up to 14 integers or floats for the Type 1/CFF `BlueValues` field. Must contain an even number of values following the Type 1/CFF specification rules.
</ParamField>

<ParamField body="postscriptOtherBlues" type="number list">
  Up to 10 integers or floats for the Type 1/CFF `OtherBlues` field. Must contain an even number of values.
</ParamField>

<ParamField body="postscriptFamilyBlues" type="number list">
  Up to 14 integers or floats for the Type 1/CFF `FamilyBlues` field. Must contain an even number of values.
</ParamField>

<ParamField body="postscriptFamilyOtherBlues" type="number list">
  Up to 10 integers or floats for the Type 1/CFF `FamilyOtherBlues` field. Must contain an even number of values.
</ParamField>

<ParamField body="postscriptStemSnapH" type="number list">
  List of horizontal stems sorted in increasing order. Up to 12 integers or floats. Corresponds to the Type 1/CFF `StemSnapH` field.
</ParamField>

<ParamField body="postscriptStemSnapV" type="number list">
  List of vertical stems sorted in increasing order. Up to 12 integers or floats. Corresponds to the Type 1/CFF `StemSnapV` field.
</ParamField>

<ParamField body="postscriptBlueFuzz" type="integer or float">
  `BlueFuzz` value. Corresponds to the Type 1/CFF `BlueFuzz` field.
</ParamField>

<ParamField body="postscriptBlueShift" type="integer or float">
  `BlueShift` value. Corresponds to the Type 1/CFF `BlueShift` field.
</ParamField>

<ParamField body="postscriptBlueScale" type="float">
  `BlueScale` value. Corresponds to the Type 1/CFF `BlueScale` field.
</ParamField>

<ParamField body="postscriptForceBold" type="boolean">
  Indicates how the Type 1/CFF `ForceBold` field should be set.
</ParamField>

<ParamField body="postscriptDefaultWidthX" type="integer or float">
  Default width for glyphs.
</ParamField>

<ParamField body="postscriptNominalWidthX" type="integer or float">
  Nominal width for glyphs.
</ParamField>

<ParamField body="postscriptWeightName" type="string">
  A string indicating the overall weight of the font. Corresponds to the Type 1/CFF `Weight` field. Should be in sync with `openTypeOS2WeightClass`.
</ParamField>

<ParamField body="postscriptDefaultCharacter" type="string">
  The name of the glyph that should be used as the default character in PFM files.
</ParamField>

<ParamField body="postscriptWindowsCharacterSet" type="integer">
  The Windows character set. See the values table below.
</ParamField>

## Converting fontinfo.plist from UFO 1 to UFO 2

Many UFO 1 keys were renamed in UFO 2 to fit the new tagged naming scheme. The table below maps each old UFO 1 key to its UFO 2 equivalent, along with any required data conversion.

| UFO 1 Key | UFO 2 Key | Conversion Notes |
|-----------|-----------|------------------|
| `menuName` | `styleMapFamilyName` | No special conversion needed. |
| `fontStyle` | `styleMapStyleName` | Convert integer to string. See table below. |
| `designer` | `openTypeNameDesigner` | No special conversion needed. |
| `designerURL` | `openTypeNameDesignerURL` | No special conversion needed. |
| `createdBy` | `openTypeNameManufacturer` | No special conversion needed. |
| `vendorURL` | `openTypeNameManufacturerURL` | No special conversion needed. |
| `license` | `openTypeNameLicense` | No special conversion needed. |
| `licenseURL` | `openTypeNameLicenseURL` | No special conversion needed. |
| `ttVersion` | `openTypeNameVersion` | No special conversion needed. |
| `ttUniqueID` | `openTypeNameUniqueID` | No special conversion needed. |
| `notice` | `openTypeNameDescription` | No special conversion needed. |
| `otFamilyName` | `openTypeNamePreferredFamilyName` | No special conversion needed. |
| `otStyleName` | `openTypeNamePreferredSubfamilyName` | No special conversion needed. |
| `otMacName` | `openTypeNameCompatibleFullName` | No special conversion needed. |
| `widthName` | `openTypeOS2WidthClass` | Convert string to integer. See table below. |
| `weightValue` | `openTypeOS2WeightClass` | No special conversion needed. |
| `ttVendor` | `openTypeOS2VendorID` | No special conversion needed. |
| `uniqueID` | `postscriptUniqueID` | No special conversion needed. |
| `fontName` | `postscriptFontName` | No special conversion needed. |
| `fullName` | `postscriptFullName` | No special conversion needed. |
| `weightName` | `postscriptWeightName` | No special conversion needed. |
| `slantAngle` | `postscriptSlantAngle` | No special conversion needed. |
| `defaultWidth` | `postscriptDefaultWidthX` | No special conversion needed. |
| `msCharSet` | `postscriptWindowsCharacterSet` | Convert bit value to integer. See table below. |
| `fondID` | `macintoshFONDFamilyID` | No special conversion needed. |
| `fondName` | `macintoshFONDName` | No special conversion needed. |
